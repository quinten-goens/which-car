# goca-barometer

Scrapes the [GOCA Barometer](https://gocabarometer.gocavlaanderen.be/) (defects found at the Flemish periodic
car inspection, per brand, model and age class) and publishes a static "which car to buy?" dashboard in
Dutch, French, German and English.

## Data

```sh
uv run python scrape.py            # polite crawl: 1 connection, 2–3 s between requests, cached in data/raw/
uv run python scrape.py --refresh  # ignore the cache and re-download
```

| file | grain | contents |
|---|---|---|
| `data/models.parquet` | model | brand, name, url, classes shown, period, total inspections, scrape time |
| `data/age_classes.parquet` | model × age class (6 per model) | bar-chart values and bar geometry (model + class average), KPI verdict, defect %, avg km, class avg km |
| `data/rubrics.parquet` | model × age class × top-10 rubric | rank, rubric code/name, model %, class %, raw text, `<`-bound flags, inline bar geometry |
| `data/barometer.parquet` | all of the above in one long table | `age_classes` left-joined to `rubrics` |

Age classes without data (fewer than 500 inspections) are kept with `has_data = False` and only the class average.

## Dashboard

`docs/` is a static site (no build step, no server):

| file | role |
|---|---|
| `index.html` + `app.js` | dashboard: overview tab and head-to-head tab |
| `about.html` | how the site was made |
| `common.js` | language, light/dark theme, (i) help tooltips |
| `i18n.js` | all texts in NL / FR / DE / EN, plus translated defect categories |
| `data.json` | generated by `build_site.py` from the parquet files (not committed) |

Preview locally:

```sh
uv run python build_site.py
python3 -m http.server -d docs     # http://localhost:8000
```

## Deploy

`.github/workflows/pages.yml` builds `docs/data.json` from the committed parquet files and publishes `docs/`
to GitHub Pages on every push to `main` (or manually via *Run workflow*). One-time setup: in the repository,
go to **Settings → Pages → Build and deployment → Source** and choose **GitHub Actions**.

To refresh the data: run `scrape.py --refresh` locally, commit the updated `data/*.parquet`, and push.
